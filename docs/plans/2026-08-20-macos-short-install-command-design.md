# macOS: короткая персональная команда установки

Дата: 2026-08-20

## Цель

Дать админке возможность формировать короткую однострочную команду macOS,
в которой вместо полного URL подписки передаётся имя пользователя. Существующая
установка с полным URL и интерактивным вводом должна остаться совместимой.

## Пользовательский интерфейс

Канонический установщик публикуется напрямую по адресу:

```text
https://sub.dostup.best/conf/macos/Dostup.sh
```

Персональная команда имеет вид:

```bash
curl -fsSL https://sub.dostup.best/conf/macos/Dostup.sh | bash -s -- user
```

Аргумент `user` преобразуется в:

```text
https://sub.92724063.xyz/conf/yaml/user.yaml
```

Полный URL по-прежнему можно передать тем же первым аргументом. Без аргумента
установщик сохраняет прежний интерактивный сценарий.

## Валидация и совместимость

Короткое имя допускает только ASCII-буквы, цифры, `_` и `-`. Пустое значение,
пробелы, точки, слеши и другие символы не преобразуются в URL. Некорректный
аргумент отклоняется до остановки Mihomo и удаления существующей установки.

Полные `http://` и `https://` URL сохраняют прежнюю семантику. Алгоритм
скачивания, обработки, проверки и сохранения YAML-профиля не меняется.

## Публикация

Файл размещается на основном сервере в:

```text
/usr/local/etc/xray/subscription/conf/macos/Dostup.sh
```

Существующий catch-all `location /` для `sub.dostup.best` уже обслуживает этот
каталог напрямую. Отдельное правило nginx и зеркальный домен не требуются.

Маршруты Android и Windows в проекте `clash_tel` не меняются. Старый URL
установщика на GitHub остаётся рабочим для обратной совместимости.

## Проверки

- `bash -n` для установщика;
- полный HTTPS URL возвращается без изменений;
- корректное короткое имя получает ожидаемый URL;
- недопустимые короткие имена отклоняются;
- пустой аргумент сохраняет интерактивный сценарий;
- публичный `Dostup.sh` побайтно совпадает с локальным файлом;
- macOS-команда загружает установщик напрямую с `sub.dostup.best`.
