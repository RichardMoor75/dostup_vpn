# macOS: безопасные фоновые обновления и fallback меню

## Цель

Сохранить текущий пользовательский сценарий и структуру подписочного профиля,
но исключить установку несовместимого профиля или ядра. Новое ядро должно
применяться автоматически, даже если пользователь месяцами не перезапускает
программу.

## Инварианты

- Входной профиль не преобразуется по правилам Linux.
- Единственное содержательное изменение профиля — замена внешнего bind
  `external-controller` с `0.0.0.0` на `127.0.0.1`; порт сохраняется.
- Windows- и Linux-установщики не меняются.
- Состав и внешний вид macOS-меню сохраняются.
- Новое ядро не запускает VPN, если пользователь ранее остановил его.

## Профиль

Обновление скачивается во временный файл, проходит базовую защиту от HTML,
точечное закрытие порта управления и затем обязательную проверку действующим
ядром через `mihomo -t`. Только после этого файл заменяет рабочий конфиг.
Работающий Mihomo получает конфиг через локальный API. Ошибка API приводит к
возврату предыдущего файла; остановленный Mihomo получает уже проверенный файл
без принудительного запуска.

## Ядро

Новое ядро скачивается рядом с рабочим, его архив обязательно сверяется с
опубликованным SHA256. Распакованный кандидат проверяет текущий профиль через
`mihomo -t` до остановки VPN.

Если VPN работает, updater выполняет короткую контролируемую остановку,
атомарно сохраняет старое ядро, устанавливает кандидат и запускает сервис.
Успех подтверждается устойчивым процессом и ответом локального API. При любой
ошибке новое ядро удаляется, старое возвращается и сервис запускается снова.
Если VPN был остановлен, проверенное ядро заменяется без запуска сервиса.

## Menu bar и старые Intel Mac

Готовый Swift-бинарник поддерживает Intel с macOS 10.15 и Apple Silicon с
macOS 11. На более старой системе отсутствие status-bar не должно мешать
установке VPN. Установщик заранее проверяет версию ОС и после компиляции либо
скачивания проверяет фактический запуск приложения. Не запустившийся компонент
и его LaunchAgent удаляются, а пользователю остаётся гарантированно рабочее
приложение `Dostup_VPN` в `~/Applications`.

Команды запуска и остановки из menu bar проходят через общий управляющий
скрипт, чтобы DNS, проверка ядра и сообщения об ошибках не расходились между
двумя реализациями.

## Проверка

- синтаксис Bash и существующие тесты аргументов;
- тест точечного преобразования профиля;
- тест отказа `mihomo -t` без замены рабочего профиля;
- тест успешной установки ядра и автоматического отката;
- статические проверки наличия version/runtime gate для status-bar;
- проверка рабочего профиля пользователя актуальным Mihomo.
