=====================================
   DOSTUP — Инструкция по установке
        для Linux (Ubuntu/Debian)
=====================================

ШАГ 1: Подключитесь к серверу по SSH

   ssh root@ваш_сервер

ШАГ 2: Скачайте установочный скрипт

   curl -fsSLo dostup-install.sh https://files.richard-moor.ru/Install/dostup_vpn/dostup-install.sh

   Текущий стабильный Linux-релиз — installer-v1.0.0.
   Следующие installer-v releases менеджер принимает только
   после сверки SHA-256 digest из GitHub Releases.

ШАГ 3: Запустите установку

   sudo bash dostup-install.sh

ШАГ 4: Введите URL подписки

   • Скрипт запросит ссылку на подписку
   • Вставьте URL и нажмите Enter

ШАГ 5: Готово!

   Dostup VPN установлен и запущен как systemd-сервис.
   Управление через команду: sudo dostup <команда>

=====================================
       КАК ПОЛЬЗОВАТЬСЯ

-------------------------------------
ПРОВЕРКА ДОСТУПА
-------------------------------------
Выполните: dostup check

Скрипт проверит доступ к сайтам через прокси:
   ✓ instagram.com — доступен (200)
   ✓ youtube.com — доступен (200)
   ✗ rutracker.org — недоступен (000)

Если сайты недоступны — VPN не работает или не запущен.

Изменить список сайтов для проверки:
   Отредактируйте файл /opt/dostup/sites.json

-------------------------------------
ИСПОЛЬЗОВАНИЕ ПРОКСИ
-------------------------------------

VPN работает как локальный прокси на порту 7890
(порт может быть другим — см. вывод установщика).

Способ 1: Разовый запуск через прокси

   HTTPS_PROXY=http://127.0.0.1:7890 HTTP_PROXY=http://127.0.0.1:7890 curl ifconfig.me

Способ 2: Алиасы в ~/.bashrc (рекомендуется)

   Добавьте в конец файла ~/.bashrc:

   alias px='HTTPS_PROXY=http://127.0.0.1:7890 HTTP_PROXY=http://127.0.0.1:7890'
   alias codex='px codex'
   alias claude='px claude'
   alias npm='px npm'
   alias pip='px pip'
   alias docker='px docker'

   Затем выполните: source ~/.bashrc
   Теперь команды codex, claude, npm, pip, docker
   будут автоматически ходить через прокси.

Способ 3: Прокси для всей сессии

   export HTTPS_PROXY=http://127.0.0.1:7890
   export HTTP_PROXY=http://127.0.0.1:7890

   Все программы в текущей сессии будут использовать прокси.
   Для отключения закройте терминал или выполните:
   unset HTTPS_PROXY HTTP_PROXY

-------------------------------------
ОБРАБОТКА ПРОФИЛЯ ДЛЯ LINUX
-------------------------------------
Поведение импорта не изменилось:
   • блок tun удаляется;
   • блок rule-providers и правила RULE-SET удаляются;
   • proxy-providers сохраняются;
   • финальный MATCH направляется в Auto Select;
   • API и DNS привязываются к loopback.

После этих преобразований итоговый профиль обязательно
проверяется командой mihomo -t до замены рабочей версии.

-------------------------------------
ОБНОВЛЕНИЕ КОНФИГА И ЯДРА
-------------------------------------
Выполните: sudo dostup restart

Скрипт автоматически:
   • Проверит обновление ядра Mihomo
   • Скачает свежий конфиг по URL подписки
   • Проверит итоговую комбинацию ядра и профиля
   • Обновит GeoIP, GeoSite и ASN (раз в 14 дней)
   • Проверит SHA-256 всех release-артефактов
   • Коротко перезапустит сервис после полной подготовки

Если новый профиль недоступен, проверенное обновление ядра
всё равно может быть применено, и наоборот. При локальной
ошибке запуска выполняется автоматический rollback.

-------------------------------------
ФОНОВЫЕ ОБНОВЛЕНИЯ
-------------------------------------
Dostup автоматически проверяет обновления дважды в неделю:
   • в понедельник и четверг около 04:00;
   • используется локальное время сервера;
   • к времени добавляется случайная задержка до 30 минут;
   • пропущенная проверка выполняется после загрузки сервера.

Проверяются менеджер, ядро Mihomo, профиль и Geo-базы.
Если значимых изменений нет, работающий VPN не перезапускается.
Если один источник недоступен, остальные безопасные обновления
всё равно могут быть применены.

Проверить расписание:
   systemctl status dostup-update.timer
   systemctl list-timers dostup-update.timer

Посмотреть журнал последних проверок:
   journalctl -u dostup-update -n 100

Запустить фоновую проверку вручную:
   sudo systemctl start dostup-update.service

Отключить автоматические проверки:
   sudo systemctl disable --now dostup-update.timer

Включить обратно:
   sudo systemctl enable --now dostup-update.timer

Если Dostup был установлен до installer-v1.0.0, один раз
повторно выполните команду установки из ШАГА 2–3 и выберите
сохранение текущей подписки. Это установит новый менеджер и timer.

-------------------------------------
СМЕНА URL ПОДПИСКИ
-------------------------------------
Если нужно изменить подписку:

1. Откройте файл настроек:
   nano /opt/dostup/settings.json

2. Измените значение "subscription_url"

3. Перезапустите: sudo dostup restart

-------------------------------------
АВТОЗАГРУЗКА
-------------------------------------
Dostup автоматически запускается при загрузке
сервера (systemd-сервис). Дополнительная настройка
не требуется.

Отключить автозагрузку:
   sudo systemctl disable dostup

Включить обратно:
   sudo systemctl enable dostup

-------------------------------------
ВОЗМОЖНЫЕ ПРОБЛЕМЫ
-------------------------------------

Не запускается / ошибка в логах:
   → Проверьте логи: dostup log
   → Или: journalctl -u dostup -n 50
   → Проверьте конфиг: cat /opt/dostup/config.yaml

Порт занят:
   → Скрипт автоматически находит свободный порт
   → Текущий порт: grep mixed-port /opt/dostup/config.yaml

Не удаётся скачать конфиг/ядро:
   → Проверьте интернет: curl -I https://github.com
   → Проверьте URL подписки в settings.json

Mihomo падает после обновления:
   → Выполните: sudo dostup rollback
   → Затем проверьте: journalctl -u dostup -n 50

   sudo systemctl daemon-reload
   sudo rm -rf /opt/dostup
   sudo rm -f /usr/local/bin/dostup
